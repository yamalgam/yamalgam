## Where things stand

Milestone 10 is implemented through Task 23. `yg` now runs jq-style filters on
a metadata-carrying YAML value model, emits YAML or JSON, exposes YAML-native
inspection and mutation filters, and performs atomic per-file `-i` edits.
`just check` passes with 1,784 nextest tests. Task 23's source annotations,
Tracey config, documentation, and commit message remain uncommitted.

## Decisions made

- Built the expression layer on jaq 3 instead of maintaining another query
  dialect. `YamlVal` supplies YAML semantics beneath jaq's grammar.
- Preserved tags, anchors, aliases, source style, raw scalar text, insertion
  order, merge keys, and non-string keys in the query model.
- Kept jq's `explode` string behavior. YAML alias materialization is
  `explode_aliases`; JSON output materializes aliases and drops metadata.
- `type` uses YAML names, `keys` preserves insertion order, and `keys_sorted`
  provides jq ordering. Mapping equality and ordering are order-sensitive.
- The numeric backend is `i64`/`f64`; checked integer overflow promotes to
  `f64`. Arbitrary-precision decimals remain future work.
- jq 1.8 compatibility is executable: 230 pass, 13 exact expected failures,
  and 8 exact skips. Stale allowlist entries and unexpected passes fail tests.
- Librebar 0.4 owns global CLI behavior. `-C` changes directory;
  `--color auto|always|never` replaces draft 01's `-C`/`-M` color flags.
- `-i` uses a same-directory tempfile, sync, permission preservation, and
  atomic replacement. It reserializes; comments and exact formatting are not
  preserved until CST-spliced mutation lands.
- The competitive bar is a YAML processor that happens to speak jq, with YAML
  fidelity as the advantage. Do not grow another parallel expression dialect.

See `docs/spec/yg-spec-draft-01-implementation-notes.md` for the full draft-01
deviation ledger.

## Landmines

- `-i` is atomic per file, not transactional across all files. If file N
  fails, files before N have already been replaced.
- `-i -s` slurps per file because in-place processing is intentionally
  per-file; normal multi-file mode is one unified stream.
- Do not rename `explode_aliases` to `explode`; that breaks jq compatibility.
- Do not annotate unshipped spec rules as implemented. The intentionally
  uncovered rules are strict comparison, comments/CST, schema pragmas,
  external resolution, validation, and future phases.
- `.config/tracey/config.styx` now registers `yamalgam-query`, but
  `tracey query validate` still needs a machine with Tracey available.
- The jq manual fixture is pinned to commit
  `603db3f57741d217ba651e61086b550a72148b83`; update the pin, corpus, and
  exact allowlist together.
