# No-Environment CLI Remediation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:test-driven-development to implement this plan task-by-task.

**Goal:** Close `env-access-always-compiled-in` by exposing the query engine's
existing environment capability policy as `yg --no-env`.

**Architecture:** Keep jq-compatible environment access as the default. Add a
precise CLI switch that selects `CompileOptions::sandboxed()` before filter
compilation, leaving the query crate as the capability owner and the CLI as a
thin policy selector.

**Tech Stack:** Rust 2024, Clap, jaq-core, cargo-nextest, Just.
